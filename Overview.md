# Design Implementation and How it works

1. Use preset 3D interactive sphere
2. Use texture overlay of known territories to emulate globe
3. Create side bar UI that shows what country the user is clicking on
4. Then create a note taking application that saves locally user's input based on what region they have clicked on
5. Ensure notes are locally saved by exiting and reopening (within same network)
